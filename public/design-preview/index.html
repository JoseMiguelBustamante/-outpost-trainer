Outpost HUD — T6 design previews

Three HUD directions for the game. Each preview has state buttons at the bottom: Normal / Storm / Tutorial / Game over. Pick one (or mix parts) to shape T6.

01 · Mission Console Mission banner + compact meter chips + power drawer + prominent SCAN. Strongest guidance; most chrome. 02 · Kid Arcade Fat gauges, giant round SCAN button, arcade storm splash. Max kid appeal; least precision. 03 · Focus Telemetry One thin status line that expands only under threat; clean 3D scene. Least hand-holding.

Design sources live in design/outpost-hud-t6/ (repo). Scope: visual language of the reference only — no water/food systems (locked Core 4).
